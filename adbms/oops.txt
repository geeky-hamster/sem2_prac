Create User Defined Data Type:
Address Type (Composite Type):
CREATE TYPE address_type AS (
	street TEXT,
	city TEXT,
	state TEXT,
	pincode VARCHAR(6)
);

Create Base Class (Superclass): 
Person Table:
CREATE TABLE Person (
	name TEXT,
	dob TEXT,
	gender CHAR(1),
	address address_type,
	phone VARCHAR(15)
);

Create Subclasses using Inheritance: 
Doctor Table:
CREATE TABLE Doctor (
    doctor_id SERIAL PRIMARY KEY,
    license_number VARCHAR(50) UNIQUE NOT NULL,
) INHERITS (Person);

Patient Table:
create table Patient (
	patient_id SERIAL PRIMARY KEY
) INHERITS (Person);

Appointment Table:
CREATE TABLE appointment (
    appointment_id SERIAL PRIMARY KEY,
    patient_id INTEGER NOT NULL,
    doctor_id INTEGER NOT NULL,
    appointment_date DATE NOT NULL,
    appointment_time TIME NOT NULL,
    reason TEXT,
    status VARCHAR(20) DEFAULT 'scheduled',
    FOREIGN KEY (patient_id) REFERENCES patient(patient_id),
    FOREIGN KEY (doctor_id) REFERENCES doctor(doctor_id)
);

Encapsulation Using Function (Method):
Code:
Create Function:
CREATE FUNCTION total_appointments(doc_id INTEGER)
RETURNS INTEGER AS $$
BEGIN
    RETURN (
        SELECT COUNT(*)
        FROM Appointment
        WHERE doctor_id = doc_id
    );
END;
$$ LANGUAGE plpgsql;

Use Function:
SELECT name, total_appointments(doctor_id)
FROM Doctor;
